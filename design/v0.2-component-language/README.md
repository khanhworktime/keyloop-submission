# Component language

Status: approved, `v0.2.1` (manager approval recorded 2026-07-14)

This milestone proves the Precision system on two high-leverage surfaces before
the remaining component library is designed. It is a Huashu HTML design
artifact, not production React code.

## Review set

- `index.html` — review gallery and decision gate.
- `components/navigation-shell.html` — desktop, tablet, and mobile navigation.
- `components/ag-grid-data-surface.html` — Community-safe table, application
  Grid View, and mobile cards.
- `component-spec.md` — shared implementation contract.
- `styles/component-foundation.css` — canonical shared presentation rules.
- `review.md` — manager feedback and promotion status.
- `validation.md` — static and visual proof.

## Provenance

- Keyloop logo: `../v0.1-brand-foundation/assets/keyloop-logo-slate.svg`.
- Foundation: `../v0.1-d-precision-guideline/design-tokens.css`.
- Icons: Iconsax free set via `iconsax-reactjs`, Rounded Linear by default and
  Bold only for selected navigation. Iconsax remains the asset owner; icons are
  used inside this product-design submission and are not redistributed as a
  standalone icon library.

## Promotion

The two proof surfaces are approved. Their grammar now promotes into buttons,
filters, forms, overlays, status, and shared-state families before responsive
screen composition begins.
