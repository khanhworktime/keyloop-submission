Navigation

Only three primary destinations.

Overview, Inventory, and Activity. Inventory Unit detail is reached from its record, not added as navigation.

Data surface

AG Grid where comparison matters.

AG Grid Community on desktop/tablet; purpose-built fast-check cards on mobile using the same query and view model.

Interaction source

Animate UI, then Base UI.

Prefer Base UI-backed Animate UI variants. Every adopted primitive inherits global Precision tokens, focus, and touch rules.

Icon language

Iconsax Rounded Linear.

Use Bold only for selected navigation. Icons support meaning; they do not decorate every label.

Supporting data

Vehicle Master stays behind Inventory.

Make, model, variant, and type remain reusable Master-owned fields. A dedicated Master library may support administration, but it is not a fourth core workflow.

Deferred module

Location capacity and placement.

Locations, Zones, Slots, assignment, movement, capacity, persistence, API contracts, and validation are outside the submission MVP.

Legacy Zone/Slot labels in fixture screens are display context only.
