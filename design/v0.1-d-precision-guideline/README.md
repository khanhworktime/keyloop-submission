# Precision guideline

Status: selected direction, `v0.1-d`

This version converts the Direction C exploration into implementation rules.
It preserves Direction A's typography and spacing, adopts Direction B's strong
widget and overlay composition, corrects the semantic palette, and strengthens
hierarchy and accessibility.

## Files

- `brand-guideline.md` — source of truth for product UI decisions.
- `design-tokens.css` — implementation-ready foundation tokens.
- `brand-kit-board.html` — presentation board source.
- `brand-kit-board.css` — board-only presentation styles.
- `previews/brand-kit-board.png` — rendered 1600 × 1000 board.

The official wordmark remains canonical at
`../v0.1-brand-foundation/assets/keyloop-logo-slate.svg`.

## Promotion rule

`v0.2-component-language` must inherit this version's hierarchy, color,
typography, focus, touch, overlay, responsive, and AG Grid rules. New patterns
require an explicit guideline amendment rather than one-off styling.
