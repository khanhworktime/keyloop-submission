# Design workspace

Design artifacts are versioned by review milestone. Existing versions remain
unchanged when a new direction is explored.

For the fastest approved-flow review, open
[`final/index.html`](final/index.html). The `final` folder is a curated entrypoint;
the versioned folders below remain the editable source evidence.

Basic design milestone: **complete** (`US-002`, 2026-07-14). Production
implementation remains tracked separately by `US-001`.

| Version | Status | Scope |
| --- | --- | --- |
| `v0.1-brand-foundation` | reviewed | Three archived directions, tokens, responsive principles, review gallery |
| `v0.1-d-precision-guideline` | selected | Approved Precision direction, hierarchy, semantic color, accessibility, brand-kit board |
| `v0.2-component-language` | approved v0.2.1 | Navigation Shell, Table/Grid Data Surface, mobile proof set |
| `v0.2.2-component-families` | approved direction | Actions & Inputs responsive component-family board |
| `v0.2.3-status-and-feedback` | approved direction | Durable status, transient feedback, and async recovery board |
| `v0.2.4-overlays-and-decisions` | early review | Popover, dialog, alert dialog, drawer/sheet, and destructive decision board |
| `v0.3-responsive-screens` | early review | Dashboard, Inventory, Inventory Unit, and Activity reviewed responsively; four additional families mapped and deferred |
| `v0.4-management-screens` | reviewed exploration | Vehicle Master, Locations, and Zone/Slot compositions retained as supporting/future design evidence |
| `v0.5-design-handoff` | implementation-ready | Supply Inventory MVP scope, core flow, responsive contract, source-of-trust, and deferred-module boundary |
| `final` | canonical review entry | Curated links to the handoff, four core screens, design language, and supporting Vehicle Master evidence |
| `v1.0-approved` | planned | Approved design system and prototype handoff |

Minor iterations use descriptive suffixes such as `v0.1-a`, `v0.1-b`, and
`v0.1-c`. Approved milestones are copied forward; older versions are retained.
